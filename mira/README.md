# MIRA (मीरा)

Mitra for Intelligent Rural Analytics. AI-driven cash flow prediction and early risk flagging for rural micro enterprises.

See the full documentation, screenshots, setup guide and demo accounts in the [root README](../README.md).

Quick start on Windows: run `start.bat` and open http://localhost:8000 (all demo passwords: `mira2026`).

The 6-minute demo walkthrough is in [DEMO.md](DEMO.md).
